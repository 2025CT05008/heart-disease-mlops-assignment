# Submission screenshots

Save genuine screenshots from your own run in this folder. Suggested evidence:

- `01-repository.png` — project structure and deliverables.
- `02-tests-and-training.png` — successful tests, training, and MLflow runs.
- `03-api-prediction.png` — local or deployed API request and response.
- `04-prometheus.png` — observed API metrics.
- `05-kubernetes.png` — Kubernetes resources, if deployed.

Do not add example or placeholder images as if they were captured from a live
run. If a component was not run, omit its screenshot and state that in the
submission.
